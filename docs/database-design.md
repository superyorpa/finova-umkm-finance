# Database Design - Finova

## Tables

### users
Menyimpan data akun pengguna.

### businesses
Menyimpan informasi UMKM.

### products
Menyimpan daftar produk dan stok.

### transactions
Menyimpan transaksi penjualan.

### transaction_details
Menyimpan detail produk dalam transaksi.

### expenses
Menyimpan pengeluaran UMKM.
